## PicBatchAutoRenamer - 图片批量自定义自动命名器
## 项目介绍
适用于Windows 10/11的轻量桌面工具，专为图片批量重命名设计，免费开源无广告。

## 核心功能
1. 批量导入多张图片
2. 自定义命名前缀、后缀
3. 自动递增序号命名
5. 一键批量统一改名

## 运行环境
- 系统：Windows10/11

## 使用方法
1. 打开软件导入图片文件夹
2. 设置自定义命名规则
3. 点击开始自动命名即可
